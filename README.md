# 범용 여행 계획 하네스

Codex와 Claude Code에서 사용하는 공통 코어 + 플랫폼 연결부 구성입니다. 날짜와 취향은 여행 실행 때 입력합니다. 별도 하네스 서버는 필요하지 않으며 각 플랫폼의 로그인·모델·도구 권한을 사용합니다.

목적지는 고정되어 있지 않습니다. 국내·해외·여러 도시 여행과 목적지 후보 비교를 지원하는 지침으로 구성했습니다. 실행 시 목적지와 예산 통화를 받으며, 도시별 시간대·국경 이동·현지 출처를 필요한 경우 조사합니다. 폴더 이름은 기존 작업 위치일 뿐 목적지를 지정하지 않습니다.

계획 데이터는 version 2입니다. 비용은 선택한 한 가지 기준 통화로 정규화하고 원래 통화·환율 근거를 보존합니다. 검사기는 혼합 통화 합산을 거절하며 날짜변경선과 시차는 타임스탬프 오프셋으로 계산합니다. 현지 시간대 규칙과 환율 사실 확인은 조사·감사 담당입니다.

## 사용

이 프로젝트 전체를 작업 폴더로 열고 **“여행 하네스를 실행해줘”**라고 요청하세요. Codex는 AGENTS.md와 `.agents/skills/travel-planner/SKILL.md`, Claude Code는 CLAUDE.md와 `.claude/skills/travel-planner/SKILL.md`를 진입점으로 사용합니다. 스킬 직접 호출은 Codex의 `$travel-planner`, Claude Code의 `/travel-planner`입니다. 새 진입점이 보이지 않으면 세션을 다시 열거나 플랫폼 연결부와 공통 SKILL.md를 읽으라고 명시하세요.

전역 설치가 아닌 프로젝트 단위 패키지입니다. 다른 위치로 옮길 때 숨김 폴더와 harness를 포함한 프로젝트 전체를 복사하세요. 진입점만 개인 스킬 폴더에 복사하면 공통 코어 경로가 연결되지 않습니다.

**“예산을 바꿔 다시 검토해줘”**, **“비 오는 날 대안으로 수정해줘”**, **“저장한 여행을 이어서 진행해줘”**도 같은 진입점에서 처리합니다.

## 구성

- 총괄: 조건 수집·작업 배분·후보 통합·일정·버전 관리
- 동적 조사: 식음료 / 명소·체험 / 이동·숙박, 필요할 때만 세분화
- 독립 감사: 핵심 사실 재확인과 여행 실행 가능성 검토
- 산출물 제작: 동결된 계획으로 여행 가이드와 요청된 문서 제작·형식 검수
- Python 검사: 시간 충돌·영업 구간·이동 여유·필수 장소·비용 검증

공통 코어는 특정 도구명에 의존하지 않습니다. adapters/codex.md와 adapters/claude.md가 현재 사용 가능한 위임·검색·파일·제작 도구로 연결합니다. Claude Code에는 조사·감사·제작용 프로젝트 에이전트 정의 3개가 포함됩니다. Python 스크립트는 에이전트를 실행하지 않습니다. 위임 도구가 없는 환경에서는 순차 실행과 독립 감사 부재를 표시합니다.

플랫폼을 전환할 때는 기존 작성 작업을 종료하고 같은 runs 상태를 읽어 재개합니다. 다른 플랫폼의 실행 중 에이전트 ID는 재사용하지 않습니다. 경로와 상태 규칙은 references/runtime.md에 있습니다. 호환 구성과 실제 모델 실행 검증 범위는 VERIFICATION.md를 확인하세요.

산출물 제작자는 사용자가 선택한 PDF·MD·DOCX·XLSX·발표자료·로컬 HTML 등의 형식을 입력받습니다. 요청에 형식이 없으면 먼저 물어보고, 해당 형식의 스킬로 제작합니다. 임의로 MD를 기본 생성하거나 실패한 형식을 다른 형식으로 대체하지 않습니다. 제작자는 지정 임시 폴더에만 쓰고, 총괄이 원본과 대조한 파일만 최종 등록합니다. **“이 일정으로 PDF 여행 가이드도 만들어줘”**처럼 요청하면 됩니다. 각 형식의 실제 생성 가능 여부는 실행 환경에 따라 확인합니다. 자세한 지침은 [산출물 제작 역할](harness/travel-planner/references/artifact-producer.md)에 있습니다.

## 검증

`python -m unittest discover -s tests -v`

가상 데이터 테스트는 웹 사실 확인을 대체하지 않습니다. 실제 장소·영업시간·가격 검증은 첫 여행 실행에서 이루어집니다. 예약·결제는 수행하지 않습니다.

설계 참고: [OpenAI 스킬 문서](https://learn.chatgpt.com/docs/build-skills), [AGENTS.md 문서](https://learn.chatgpt.com/docs/agent-configuration/agents-md). 역할별 상세 계약은 스킬의 references에 있습니다.
