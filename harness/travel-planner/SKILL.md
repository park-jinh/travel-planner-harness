# 여행 설계사

이 스킬은 플랫폼과 무관한 공통 코어다. 먼저 `references/runtime.md`와 호스트 연결부를 읽는다. 별도 API 서버나 백그라운드 실행기는 아니다. 경로·기능 탐지·플랫폼 전환 규칙은 runtime 계약을 따른다.

## 실행

먼저 `roles/coordinator.md`를 읽는다. 역할별 지침 경로는 `roles/registry.json`이 단일 기준이다. 위임 시 배정 역할의 파일과 공통 계약을 반드시 읽도록 전달한다. 등록되지 않은 전문 역할은 총괄이 책임·입력·검사항목·출력·종료조건을 명시한 작업 지시서를 먼저 만든 뒤 배정한다.

1. `references/protocol.md`를 읽는다. 기존 `runs/<여행ID>/state.json`이 있으면 먼저 복구한다. 여행ID는 영문·숫자·하이픈만 사용하고 사용자 문자열을 경로로 직접 사용하지 않는다. 새 여행이면 기존 디렉터리를 덮어쓰지 않는다.

   조건 변경은 protocol의 revision 증가·기존 원본 무효화부터 수행한다. 재개·감사·산출물 제작 시 current_source로 원본을 선택한다. 제작 job은 호출 전에 저장하고 중단 복구는 artifact-producer의 재등록 절차를 따른다.
2. 최초 여행 실행에서만 목적지(국가·도시, 여러 곳 가능), 날짜·기간, 출발/도착 조건, 인원, 이동수단, 예산 범위·통화·기준, 취향, 필수 방문, 식사·보행 제약, 확정 예약을 수집한다. 목적지 미정이면 계절·출발지·예산·취향을 바탕으로 후보 지역부터 비교한다. 대화에 있는 정보는 다시 묻지 않는다. 미정 조건은 null로 유지하며 탐색은 가능하지만 날짜 확정 일정으로 발표하지 않는다.
3. `references/roles.md`에 따라 필요한 조사 묶음을 구성한다. 위임 실행 전 예상 조사자 수와 라운드를 한 줄로 사용자에게 알린다(coordinator.md 참고). 실제 서브에이전트를 호출하고 결과를 수신한다. 총괄이 지역 거점과 요구사항을 정리하는 동안 독립 조사를 병행한다. 현재 도구의 한도를 확인하고 총괄 포함 최대 4명, 조사자 최대 3명을 기본 상한으로 한다. 하위 재위임은 금지한다.
4. 후보를 주소·지점·공식 식별자로 중복 제거한다. 분야별 상위 3개를 기본으로 하되 필수 장소와 대체 후보를 포함한다. 단순 인기 순위 대신 필수 조건을 먼저 적용하고 취향, 동선, 휴식, 비용, 근거 수준을 비교한다. 식당·카페를 불필요하게 별도 조사하지 않는다.
5. 물류 담당(2개 도시 이상 이동 또는 숙박 3박 이상이면 숙박 담당을 discovery-lodging으로 별도 배정, roles.md 참고)에게 선택 후보 사이의 실제 이동 구간과 숙박 권역을 검증시킨다. 체류·대기·이동·휴식을 명시해 일정 초안을 만들고 날짜별 영업 구간을 반영한다. 직선거리로 대중교통 시간을 확정하지 않는다.
6. 날짜 미정이면 protocol의 탐색 초안 경로를 사용한다. 날짜 확정 후 `scripts/validate_plan.py`로 계획 JSON을 검사한다. 별도의 감사 에이전트에게 중요 사실 재확인과 선호·접근성·휴식·대안 검토를 요청한다. 숫자 검사 통과만으로 여행 가능성을 보증하지 않는다.
7. 실패한 항목만 담당자에게 재조사시킨다. 기본 수정 2회 후 해결되지 않으면 조건부 초안으로 제공한다. 미확인 사항을 숨기거나 사용자 제약을 완화해 통과시키지 않는다. 수정 후 재감사는 protocol의 부분 재감사 조건을 만족할 때만 scope=scoped로 요청한다.
8. `runs/<여행ID>/`에 state.json, candidates.json, decisions-v001.md, plan-v001.json, audit-v001.md를 저장한다. 이후 버전은 증가시키며 이전 결과를 보존한다. 날짜 미정이면 plan 대신 exploration 문서를 저장한다.
9. `references/artifact-producer.md`를 읽고 실제 artifact-producer 서브에이전트에 산출물 제작을 배정한다. 사용자가 요청한 형식(PDF, MD 등)을 입력으로 받는다. 기존 대화에 형식이 없으면 총괄이 먼저 물어보고, 선택된 형식만 제작한다. 초안도 제작 가능하되 탐색/조건부 상태를 그대로 표시한다. 총괄은 원본 대조와 파일 검수를 완료한 뒤 산출물을 등록하고 링크를 제공한다. 제작 도구가 없으면 순차 제작으로 전환한 사실을 알린다.

## 도구와 스킬

특정 국가·도시·언어·통화를 기본 여행 조건으로 가정하지 않는다. 현지 운영자·관광청·교통기관과 현지어 검색을 필요에 따라 활용한다. 해외·국경 이동이 있으면 관련 조건만 추가 조사한다. 여권번호 같은 식별정보 없이 국적·거주지·경유 조건 등 필요한 정보만 받아 공식 입국/경유 규정, 공항 여유, 수하물, 현지 휴일과 접근성을 확인한다. 미확인 규정을 단정하지 않는다. 시간은 장소별 현지 시간과 UTC 오프셋을 표시하고 일광절약시간·날짜변경선을 고려한다. 원화 환산을 기본값으로 삼지 않는다.

웹 검색과 공식/운영자 페이지로 변동 정보를 조회한다. 검색 요약만 읽고 확인 완료로 처리하지 않는다. 지도·교통 정보가 도구로 접근되지 않으면 조회 가능한 출처를 사용하되 해결되지 않은 이동시간은 추정으로 남긴다. 새로운 서비스 가입이나 유료 도구를 기본 의존성으로 두지 않는다.

사용 가능한 스킬 목록을 확인하고 필요한 것만 읽는다. PDF·문서·스프레드시트 출력은 해당 형식을 요청받았을 때 관련 스킬을 사용한다. 시각화는 일정 비교에 도움이 될 때 사용한다. 이미지 생성은 장소 사실의 근거로 사용하지 않는다. deep-research는 사용자가 심층 조사를 요청한 경우에만 사용한다. 모든 스킬을 한 번에 로드하지 않는다.

## 완료 기준

필수 입력이 확정되고 코드 검사 error가 없으며 독립 감사에서 차단 결함이 없으면 '검증된 일정안'으로 표시한다. 이는 실시간 예약 보장이나 무오류 보장이 아니다. warnings, 예약 미완료, 추정 가격과 확인 시점은 그대로 표시한다. 독립 감사가 없거나 중요한 사실이 미확인이면 '조건부 초안'이다.
