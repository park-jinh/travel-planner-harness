# 공통 실행 계약

진입점이 선택한 연결부를 읽고 실제 기능을 확인한 다음 공통 절차를 실행한다. 연결부가 없으면 현재 실행 호스트에 맞는 adapters 문서를 선택한다. 임의로 다른 플랫폼 도구명을 실행하지 않는다.

필요 기능: delegate(역할·지시서 → 결과), search/read_source(질문/URL → 근거), ask(질문 → 입력), read/write/run/check(로컬 상태·검사), render(원본·형식 → 파일·검수). 이것들은 추상 기능명이며 실행 가능한 API가 아니다. 실제 도구 호출은 연결부가 지정한다.

delegate가 없으면 역할을 순차 수행하고 독립 감사 미실시로 표시한다. 웹이 없으면 외부 사실을 verified로 만들지 않는다. Python이 없으면 코드 검사 not_run으로 표시하고 검증된 일정으로 승격하지 않는다. 렌더러 부재는 요청 형식의 실패이며 형식을 임의 대체하지 않는다.

project_root는 공통 SKILL.md가 위치한 디렉터리의 부모(harness)의 부모다. core_root는 공통 SKILL.md가 있는 디렉터리다. 공통 문서의 references/scripts 경로는 core_root 기준, runs는 project_root 기준이다. 명령 실행 전 절대경로로 해석한다.

플랫폼 전환은 같은 프로젝트와 runs를 사용한다. state의 경로는 새 저장 시 project_root 상대경로로 보존하고 실제 작업 지시서에만 절대경로를 전달한다. 기존 절대경로는 같은 프로젝트 안임을 확인한 후 상대경로로 이관한다. 다른 컴퓨터에서 이전 경로를 찾을 수 없으면 파일명으로 추측하지 않고 원본 위치를 확인한다. 원본 내용 해시는 유지한다.

state.runtime은 현재 호스트의 기능 기록이며 재개할 때 갱신한다. job의 호스트 실행 식별자는 runtime_handle={platform, session, id}로 따로 저장한다. 다른 호스트에서는 이 식별자를 재사용하지 않는다. 전환 전에 이전 호스트의 작성 작업이 종료됐는지 확인하고, 알 수 없으면 중복 쓰기/등록을 보류한다. 사용자가 이전 실행 종료를 확인하면 새 task_id로 재배정할 수 있다. 총괄 단일 작성자 원칙과 revision·해시 검사는 플랫폼과 무관하게 적용한다.
